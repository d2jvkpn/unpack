# Unpack Go CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a secure Go CLI named `unpack` that extracts ZIP, TAR, TAR.GZ, and TGZ archives
with smart default destinations and optional legacy Chinese filename decoding.

**Architecture:** Scan every archive into common entry metadata before writing. Shared planning
code decodes names, selects a destination root, strips wrappers when required, and validates paths;
format-specific code then streams regular files into the approved destinations.

**Tech Stack:** Go 1.27, Go standard library archive packages, and `golang.org/x/text` for GBK.

**Spec:** `docs/records/superpowers/2026-08-23_unpack.design.md`

## Global Constraints

- The module and generated command are named `unpack`.
- Supported extensions are `.zip`, `.tar`, `.tar.gz`, and `.tgz`, matched case-insensitively.
- `--cn` decodes legacy ZIP names and invalid UTF-8 TAR names as GBK.
- `--output-dir` has no short alias.
- A default extraction with multiple top-level items uses the archive basename as its directory.
- A default extraction with one top-level item writes directly into the current directory.
- An explicit output directory strips one sole top-level directory wrapper.
- Existing files are skipped and never overwritten.
- Only regular files and directories are extracted; links and special entries are errors.
- All archive entries are validated before that archive writes any data.
- CLI messages and README prose are in English.
- The only non-standard production dependency is `golang.org/x/text`.
- Do not create Git commits unless the user invokes `:git-commit` or a dedicated commit skill.

```go
package main

import (
	"fmt"
	"io/fs"
	"path/filepath"
	"strings"
)

type archiveFormat uint8

const (
	formatZIP archiveFormat = iota + 1
	formatTAR
	formatTarGzip
)

type entryKind uint8

const (
	entryFile entryKind = iota + 1
	entryDirectory
)

type archiveEntry struct {
	Name        string
	Kind        entryKind
	Mode        fs.FileMode
	SourceIndex int
}

func detectFormat(path string) (archiveFormat, error) {
	lower := strings.ToLower(path)
	switch {
	case strings.HasSuffix(lower, ".tar.gz"), strings.HasSuffix(lower, ".tgz"):
		return formatTarGzip, nil
	case strings.HasSuffix(lower, ".tar"):
		return formatTAR, nil
	case strings.HasSuffix(lower, ".zip"):
		return formatZIP, nil
	default:
		return 0, fmt.Errorf("unsupported archive format: %s", filepath.Base(path))
	}
}

func archiveBaseName(path string, format archiveFormat) string {
	name := filepath.Base(path)
	lower := strings.ToLower(name)
	suffix := map[archiveFormat]string{
		formatZIP: ".zip", formatTAR: ".tar", formatTarGzip: ".tgz",
	}[format]
	if format == formatTarGzip && strings.HasSuffix(lower, ".tar.gz") {
		suffix = ".tar.gz"
	}
	return name[:len(name)-len(suffix)]
}
```

```go
package main

import (
	"fmt"
	"strings"

	"golang.org/x/text/encoding/simplifiedchinese"
	"golang.org/x/text/transform"
)

func decodeArchiveName(raw string, chinese bool, legacy bool) (string, error) {
	if !chinese || !legacy {
		return raw, nil
	}
	decoded, _, err := transform.String(simplifiedchinese.GBK.NewDecoder(), raw)
	if err != nil {
		return "", fmt.Errorf("decode GBK filename %q: %w", raw, err)
	}
	if strings.ContainsRune(decoded, '\uFFFD') {
		return "", fmt.Errorf("decode GBK filename %q: invalid byte sequence", raw)
	}
	return decoded, nil
}
```
